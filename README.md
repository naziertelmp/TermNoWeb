## 📖 What is WebTerm?

**WebTerm** gives you a **Linux terminal* accessible directly from your **phone or desktop browser** - no VPN, no apps, no registration required.

---

## ✨ Features

- 🌐 **Browser Only** - No apps, no VPN
- 📱 **Mobile Friendly** - Works on phone browsers
- 🔒 **Secure** - Cloudflare encrypted tunnel
- 🛠️ **Root Access** - Full sudo privileges
- 🔗 **Instant Link** - Get a URL and connect

## 🛠️ Tech Stack

- **OS**: Ubuntu
- **Tunnel**: Cloudflare Tunnel
